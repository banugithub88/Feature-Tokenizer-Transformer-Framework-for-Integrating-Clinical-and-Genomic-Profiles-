Feature Tokenizer Transformer for Breast Cancer Prognosis
This repository implements a Feature Tokenizer Transformer (FT-Transformer) for integrating clinical and genomic profiles in breast cancer prognosis. The model predicts subtype classification, relapse risk, and survival outcomes using multi-task learning. The dataset is sourced from CBioPortal. The FT-Transformer leverages self-attention mechanisms for learning complex feature dependencies. Performance evaluation demonstrates superior results compared to traditional models.
